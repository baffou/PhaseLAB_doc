.. dropdown:: **moveTo** |subTitle| Moves the wavelength to the specified value. |/subTitle|
    
    .. raw:: html
      
        <p class="title">Syntax</p>
    
    .. code-block:: matlab

        % prototype
        obj.moveTo(lambda)

    .. raw:: html
      
        <p class="title">Description</p>

    ``obj.moveTo(lambda)`` physically changes the illumination wavelength of the physical monochromator ``obj`` to ``lambda``.
