.. dropdown:: **set_dichroMax** |subTitle| Sets the maximum dichroism, used for image display. |/subTitle|

    .. raw:: html
      
        <p class="title">Syntax</p>

    .. code-block:: matlab

        objList.set_dichroMax(val)

        % examples
        objList.set_dichroMax(0.2)



    .. raw:: html
      
        <p class="title">Description</p>

    ``objList.set_dichroMax(val)`` assigns ``val`` to the property ``dichroMax``. This property is used when the dichroism image needs to be exported, or displayed using the ``figure`` method and the associated GUI.
