.. dropdown:: **set_retMax** |subTitle| Sets the maximum retardance, used for image display. |/subTitle|

    .. raw:: html
      
        <p class="title">Syntax</p>

    .. code-block:: matlab

        objList.set_retMax(val)

        % examples
        objList.set_retMax(30e-9)



    .. raw:: html
      
        <p class="title">Description</p>

    ``objList.set_retMax(val)`` assigns ``val`` to the property ``retardanceMax``. This property is used when the retardance image needs to be exported, or displayed using the ``figure`` method and the associated GUI.
