.. dropdown:: **dichro** |subTitle| Returns the dichroism (i.e. diattenuation) image. |/subTitle|

    .. raw:: html
      
        <p class="title">Syntax</p>

    .. code-block:: matlab

        Dic = obj.dichro();
        [Dic, phi] = obj.dichro();

    .. raw:: html
      
        <p class="title">Description</p>

    ``[Dic, phi] = obj.dichro();`` returns the dichroism image ``Dic``, and optionally its orientation angle ``phi``.
