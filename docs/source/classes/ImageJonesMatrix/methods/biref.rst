.. dropdown:: **biref** |subTitle| Returns the birefringence image. |/subTitle|

    .. raw:: html
      
        <p class="title">Syntax</p>

    .. code-block:: matlab

        Bir = obj.biref();
        [Bir, phi] = obj.biref();

    .. raw:: html
      
        <p class="title">Description</p>

    ``[Bir, phi] = obj.biref();`` returns the birefringence image ``Bir``, and optionally its orientation angle ``phi``.
