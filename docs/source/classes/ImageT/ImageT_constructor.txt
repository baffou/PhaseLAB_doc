Constructor
-----------

.. dropdown:: **Constructor**

    .. raw:: html
        
        <p class="title">Syntax</p>

    .. code-block:: matlab
        :class: custom-code

        obj = ImageT()
        obj = ImageT(TMP, HSD) 
        obj = ImageT(TMP, HSD, W) 
        obj = ImageT(TMP, HSD, W, T) 

    .. raw:: html
        
        <div class="title">Description</div>

    ``obj = ImageT()`` creates an empty *ImageT* object.

    |hr|

    ``obj = ImageT(TMP, H, W, T)`` creates an *ImageT* object, ``TMP`` defining the temperature image, ``HSD`` the heat source density image, ``W`` the intitial waverfront/OPD image from which the temperaure and heat source density image have been calculated, and ``T`` the initial transmittance image. Each of these inputs is optional.

    In principle, this constructor should never be used. **ImageT** objects are automatically created by the :ref:`TMPprocess <The_TMPprocess_method>` method of the **ImageQLSI** class.
