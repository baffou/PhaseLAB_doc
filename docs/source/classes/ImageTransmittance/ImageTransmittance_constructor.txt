Constructor
-----------

.. dropdown:: **Constructor**

    .. raw:: html
        
        <p class="title">Syntax</p>

    .. code-block:: matlab
        :class: custom-code

        obj = ImageTransmittance()
        obj = ImageTransmittance(N)
        obj = ImageTransmittance(to, te, phi, IL) 
        obj = ImageTransmittance(______, Name, Value) 

    .. raw:: html
        
        <div class="title">Description</div>

    ``obj = ImageTransmittance()`` creates a void *ImageTransmittance* object.

    |hr|

    ``obj = ImageTransmittance(N)`` creates an array of ``N`` void transmittance objects.

    |hr|

    ``obj = ImageTransmittance(to, te, phi, ME)`` creates a transmittance object from the specification of the eigen transmittances :math:`t_o` and  :math:`t_e`, the rotation angle :math:`\phi` and incident light as an |Illumination| object ``IL``.

    |hr|

    Optional values can be indicated, namely the birefringence angle, using the Name :matlab:`'phib'` and the dichroism angle using the Name :matlab:`'phib'`.
