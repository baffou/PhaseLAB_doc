
.. dropdown:: **setExpTime** |subTitle| Sets the camera exposure time, in ms. |/subTitle|

    .. raw:: html
      
        <p class="title">Syntax</p>
    
    .. code-block:: matlab

        % prototypes
        obj.setExpTime(tau);

        % examples
        obj.setExpTime(80);


    .. raw:: html
      
        <p class="title">Description</p>

    ``obj.setExpTime(tau)``  sets the exposure time of the camera to the value ``tau``, expressed in milliseconds.
