.. dropdown:: **removeRL** |subTitle| Removes the relay lens object from the CGcamera. |/subTitle|

    .. raw:: html
      
        <p class="title">Syntax</p>
    
    .. code-block:: matlab

        obj.removeRL();

    .. raw:: html
      
        <p class="title">Description</p>

    ``obj.removeRL()`` deletes the RL attribute of the object, meaning that the CGM camera is no longer endowed with a relay lens.
