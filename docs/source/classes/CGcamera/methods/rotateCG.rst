.. dropdown:: **rotateCG** |subTitle| Sets the Camera QLSI grating angle to a defined value. |/subTitle|

    .. raw:: html
      
        <p class="title">Syntax</p>
    
    .. code-block:: matlab

        obj.rotateCG(theta);

    .. raw:: html
      
        <p class="title">Description</p>

    ``obj.rotateCG(val)`` modifies the ``CG`` (cross-grating) property of the **CGcamera** object, and in particular, it sets its property ``theta`` to the specified angle.
