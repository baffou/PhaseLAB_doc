Live imaging
============

PhaseLAB enables live imaging using a :abbr:`GUI (graphical user inerface)` if some specific cameras are used. The GUi is launched using the matlab command:

.. code-block:: matlab
    :linenos:

    LIVE

.. figure:: /images/LIVE_GUI.png
    :width: 1200
    :align: center

For the moment, no detailed description of this GUI exist. A brief overview of the functionalities are just given here:

- live imaging of interferogram, wavefront, intensity, wavefront gradients, dry mass density, PDCM, Rytov field, and polar images
- reference acquisition
- snapshot acquisition
- burst acquisition
- N image averaging
- interferogram/reference recording
- long automatic recording
- setting the exposure time
- setting the ROI
- switch from low to high resolution imaging
- live display of Fourier transform
- live removal of coma
- multicolor imaging
- multipolar imaging
- parallel control of a PI stage
- parallel control of a monochromator
- automatic control of a Thorlabs shutter



.. note::

    There is a simulation ('simu') mode for testing and practicing with the GUI without connecting an actual microscope/camera system.
